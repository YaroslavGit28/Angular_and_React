## Работа с Fetch API и формами в React

### Описание работы

В ходе выполнения практической работы были изучены возможности React для работы с внешними API, асинхронными запросами, обработкой пользовательского ввода и созданием интерактивных форм.

Практическая работа состоит из двух самостоятельных проектов:

- **чпсть 5** — работа с Fetch API и асинхронными запросами;
- **часть 6** — работа с формами, валидацией и хуком `useRef`.

# Проект 1. Fetch API

## Цель работы

Изучить получение данных с внешних API, обработку состояний загрузки и ошибок, а также научиться работать с асинхронными запросами.

### Реализованные задания

#### 1. Приложение «Факты о кошках»

Функциональность:

- загрузка случайного факта;
- автоматическая загрузка при открытии страницы;
- кнопка «Ещё факт»;
- обработка состояния загрузки;
- обработка ошибок.

Используемый API:

- https://catfact.ninja/fact

---

#### 2. Приложение «Погода»

Реализовано:

- ввод названия города;
- получение координат через Geocoding API;
- запрос текущей температуры через Open-Meteo;
- отображение температуры;
- обработка ошибок и состояния загрузки.

Используемые API:

- https://geocoding-api.open-meteo.com
- https://api.open-meteo.com

---

#### 3. Пагинация

Реализовано:

- загрузка списка постов;
- отображение по 10 записей;
- переход между страницами;
- отображение текущей страницы.

Используемый API:

- https://jsonplaceholder.typicode.com

---

#### 4. Поиск с debounce

Реализовано:

- поле поиска;
- задержка 500 мс перед поиском;
- использование `setTimeout`;
- очистка предыдущего таймера;
- фильтрация списка.


## Основные файлы

| Файл | Назначение |
|------|------------|
| `src/App.jsx` | Главный компонент приложения |
| `src/components/CatFact.jsx` | Получение случайного факта о кошках |
| `src/components/Weather.jsx` | Получение текущей погоды |
| `src/components/Posts.jsx` | Пагинация списка постов |
| `src/components/Search.jsx` | Поиск с debounce |
| `src/index.css` | Стили приложения |

# Проект 2. Работа с формами

## Цель работы

Освоить создание управляемых компонентов, валидацию форм, использование `useRef` и построение многошаговых интерфейсов.

### Реализованные задания

#### 1. Форма отзыва

Реализовано:

- поле имени;
- выбор оценки;
- текст отзыва;
- проверка минимальной длины;
- блокировка кнопки отправки;
- очистка формы после успешной отправки.

---

#### 2. Форма с зависимыми полями

Реализовано:

- выбор страны;
- отображение списка городов;
- автоматическое обновление списка городов при смене страны.

---

#### 3. Фокус на первое неверное поле

Использован хук `useRef`, который переводит курсор в первое поле с ошибкой после попытки отправки формы.

---

#### 4. Файловый инпут

Реализовано:

- скрытый элемент `<input type="file">`;
- открытие выбора файла через кнопку;
- отображение имени выбранного файла.

---

#### 5. Таймер неактивности

Использовано:

- `useRef`;
- `useEffect`;
- `setTimeout`.

Через 30 секунд бездействия появляется сообщение:

> «Всё ещё с нами?»

---

#### 6. Многошаговая форма

Реализовано:

- три последовательных шага;
- хранение общего состояния формы;
- переходы между шагами;
- проверка заполнения данных;
- подтверждение перед отправкой.

---

## Основные файлы

| Файл | Назначение |
|------|------------|
| `src/App.jsx` | Главный компонент приложения |
| `src/components/ReviewForm.jsx` | Форма отзыва |
| `src/components/CountryForm.jsx` | Зависимые поля страны и города |
| `src/components/FileUpload.jsx` | Работа с файловым инпутом |
| `src/components/InactiveTimer.jsx` | Таймер активности пользователя |
| `src/components/MultiStepForm.jsx` | Многошаговая форма |
| `src/index.css` | Стили проекта |

---

# Запуск проектов

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

# Вывод

В ходе выполнения практической работы были разработаны два самостоятельных React-приложения. Первый проект посвящен получению данных с внешних сервисов и обработке асинхронных запросов, включая работу с погодой, фактами о кошках, пагинацией и поиском с задержкой. Второй проект направлен на изучение работы с пользовательскими формами, их валидацией, использованием хука `useRef`, обработкой файлового ввода и созданием многошаговых интерфейсов.

В результате выполнения работы были закреплены практические навыки разработки современных React-приложений, организации компонентов и применения основных хуков React.
