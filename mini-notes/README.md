# Мини-заметки

Данный проект представляет собой одностраничное приложение (SPA), разработанное с использованием Angular. Приложение позволяет просматривать, создавать и удалять заметки, взаимодействуя с локальным REST API, реализованным с помощью `json-server`.

В ходе выполнения проекта были реализованы следующие возможности:

- создана навигация между страницами с использованием Angular Router;
- реализована главная страница приложения;
- создан сервис `NoteService` для работы с REST API;
- выполнено получение списка заметок через `HttpClient`;
- реализовано отображение списка заметок с использованием директив `@if` и `@for`;
- добавлен индикатор загрузки данных и обработка ошибок при обращении к серверу;
- разработана форма создания заметок на основе Reactive Forms;
- реализована валидация полей формы с использованием `Validators.required` и `Validators.minLength`;
- добавлено отображение сообщений об успешном создании заметки и ошибках при сохранении;
- реализовано удаление заметок с обновлением списка без перезагрузки страницы;
- данные приложения хранятся в локальной базе `db.json`, обслуживаемой `json-server`;
- выполнена production-сборка приложения для проверки готовности проекта к развертыванию.

Для запуска проекта необходимо установить зависимости:

```bash
npm install
```

Запустить локальный сервер данных:

```bash
npx json-server --watch db.json --port 3000
```

После запуска API необходимо запустить Angular-приложение:

```bash
ng serve
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:4200
```

Для создания production-сборки используется команда:

```bash
ng build --configuration production
```

После успешной сборки готовая версия приложения находится в папке `dist/`.
