# HybridApp

Учебный проект, в котором реализовано ASP.NET Core Web API и два клиентских приложения: React и Angular. Оба клиента используют один и тот же backend и могут обращаться к общему API.

Проект создавался для изучения взаимодействия нескольких frontend-приложений с одним сервером и настройки их совместной работы.

## Используемые технологии

- ASP.NET Core
- React + Vite
- Angular
- TypeScript
- C#
- HTML
- CSS

## Структура проекта

```
HybridApp.Server
│
├── ClientApp
│   ├── react
│   └── angular
│
├── Controllers
├── Properties
├── wwwroot
├── Program.cs
└── HybridApp.Server.csproj
```

## Возможности проекта

- единый Web API для двух клиентских приложений;
- отдельный React-клиент;
- отдельный Angular-клиент;
- маршрутизация через ASP.NET Core;
- возможность дальнейшего добавления авторизации и базы данных;
- автоматическая сборка клиентских приложений при публикации проекта.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <ссылка_на_репозиторий>
cd HybridApp.Server
```

### 2. Запуск сервера

```bash
dotnet restore
dotnet run
```

### 3. Запуск React

Открыть новый терминал:

```bash
cd ClientApp/react
npm install
npm run dev
```

### 4. Запуск Angular

Открыть ещё один терминал:

```bash
cd ClientApp/angular
npm install
npx ng serve
```

## Использование

После запуска сервер предоставляет API, к которому могут обращаться оба клиентских приложения. React и Angular работают независимо друг от друга, но используют общий backend.

- создано React-приложение;
