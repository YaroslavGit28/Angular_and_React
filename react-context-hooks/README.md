## Context API, useReducer и пользовательские хуки в React

### Описание работы

В ходе выполнения практической работы были изучены возможности React Context API, хука `useReducer`, а также создание собственных (кастомных) хуков. Кроме этого была рассмотрена оптимизация производительности компонентов с помощью `React.memo`.

Практическая работа состоит из трех частей:

- **Часть 9** — работа с Context API и `useReducer`;
- **Часть 10** — создание кастомных хуков и оптимизация компонентов.
- **Screen_HW** - скрины выполненной работы


---

# Часть 9. Context API

## Цель работы

Изучить механизм передачи данных между компонентами без использования prop drilling, научиться применять `Context API` и управлять состоянием приложения через `useReducer`.

---

## 1. Переключение темы

Реализовано:

- создание `ThemeContext`;
- переключение между светлой и тёмной темой;
- сохранение выбранной темы в `localStorage`;
- автоматическое восстановление темы после перезагрузки страницы.

---

## 2. Авторизация через Context

Реализовано:

- создание `AuthContext`;
- хранение текущего пользователя;
- функции `login()` и `logout()`;
- отображение состояния авторизации.

---

## 3. Корзина товаров

Реализовано:

- создание `CartContext`;
- использование `useReducer`;
- добавление товаров;
- изменение количества товаров;
- удаление товаров;
- автоматический расчёт общей стоимости заказа.

# Часть 10. Пользовательские хуки

## Цель работы

Изучить создание собственных хуков React и способы оптимизации повторного рендеринга компонентов.

---

## 1. useDebounce

Реализовано:

- собственный хук `useDebounce`;
- задержка обработки ввода пользователя на 500 мс;
- отображение сообщения **«Печатает...»** во время ожидания;
- фильтрация списка после завершения ввода.

---

## 2. usePrevious

Реализовано:

- собственный хук `usePrevious`;
- сохранение предыдущего значения с помощью `useRef`;
- отображение текущего и предыдущего значения счётчика.

---

## 3. React.memo

Реализовано:

- оптимизация списка с помощью `React.memo`;
- проверка отсутствия лишних перерисовок через `console.log`;
- повторный рендер происходит только при изменении свойств компонента.

---

# Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить приложение:

```bash
npm run dev
```

После запуска проект будет доступен по адресу:

```text
http://localhost:5173
```

# Вывод

В ходе выполнения практической работы были изучены основные способы организации общего состояния в React с использованием Context API и `useReducer`. Также были разработаны собственные хуки `useDebounce` и `usePrevious`, позволяющие повторно использовать логику в различных компонентах приложения. Дополнительно была рассмотрена оптимизация производительности интерфейса с помощью `React.memo`, что позволяет избежать лишних перерисовок компонентов. Выполненная работа закрепила практические навыки разработки современных React-приложений и использования основных возможностей библиотеки React.
