## React Hook Form и TanStack Query

- **Screen_HW** - скрины выполненной работы

### Описание работы

В ходе выполнения практической работы были изучены возможности библиотеки React Hook Form для создания и валидации форм, а также библиотеки TanStack Query для получения, кэширования и изменения данных, получаемых с сервера.

Практическая работа состоит из двух частей.

---

# Часть 11. React Hook Form

### Форма логина

Была разработана форма авторизации с полями электронной почты и пароля. Для проверки корректности введённых данных использовалась библиотека Zod. Кнопка отправки формы становится активной только после успешного прохождения валидации всех полей.

В результате были реализованы:

- форма входа с полями email и password;
- валидация данных с помощью Zod;
- отображение сообщений об ошибках;
- блокировка кнопки отправки при наличии ошибок;
- очистка формы после успешной отправки.

---

### Динамические поля формы

Была создана форма оформления заказа с использованием хука `useFieldArray`. Пользователь может добавлять и удалять товары, а при отправке формы формируется массив объектов с информацией о заказе.

В результате были реализованы:

- динамическое добавление товаров;
- удаление товаров из формы;
- работа с массивом полей;
- отправка данных формы.

---

### Кастомная ошибка сервера

Была реализована обработка ошибки, полученной от сервера. Если введённый адрес электронной почты уже используется, с помощью метода `setError()` отображается сообщение об ошибке непосредственно у соответствующего поля.

В результате были реализованы:

- имитация ответа сервера;
- вывод серверной ошибки;
- использование метода `setError()`;
- отображение сообщения для поля email.

---

# Часть 12. TanStack Query

### Просмотр деталей поста

Была реализована загрузка списка постов и получение подробной информации о выбранном посте. После выбора элемента списка выполняется отдельный запрос на получение его содержимого.

В результате были реализованы:

- загрузка списка постов;
- получение информации о выбранном посте;
- отдельный запрос для деталей записи;
- отображение данных после загрузки.

---

### Оптимистичное удаление

Была реализована технология оптимистичного обновления данных. После нажатия кнопки удаления запись сразу исчезает из списка, не дожидаясь ответа сервера. При возникновении ошибки первоначальное состояние списка автоматически восстанавливается.

В результате были реализованы:

- удаление записи;
- оптимистичное обновление кэша;
- восстановление данных при ошибке;
- повторная синхронизация данных после завершения операции.

---

### Пагинация

Была реализована постраничная загрузка данных. Переключение между страницами выполняется с помощью кнопок «Назад» и «Вперёд», при этом для каждой страницы используется отдельный ключ запроса.

В результате были реализованы:

- загрузка данных по страницам;
- переключение между страницами;
- использование отдельных ключей запросов;
- повторная загрузка данных при смене страницы.

---

# Вывод

В ходе выполнения практической работы были освоены основные возможности библиотек React Hook Form и TanStack Query. Были реализованы формы с клиентской и серверной валидацией, динамические поля ввода, обработка ошибок, получение данных с сервера, отображение подробной информации, оптимистичное обновление данных и постраничная загрузка записей. Выполненные задания позволили закрепить навыки создания современных React-приложений с использованием популярных библиотек для работы с формами и серверными данными.
