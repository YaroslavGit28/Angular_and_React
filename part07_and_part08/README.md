## React: localStorage и React Router

### Описание проекта

В рамках данной практической работы были выполнены задания по изучению хранения данных в браузере с помощью `localStorage`, созданию собственного React-хука, а также разработке многостраничного приложения с использованием библиотеки **React Router**.

Работа состоит из двух самостоятельных мини-проектов:

- **Часть 7** — работа с `localStorage`;
- **Часть 8** — маршрутизация (React Router).

# Часть 7. Todo с использованием localStorage

## Цель работы

Изучить способы сохранения данных в браузере и научиться синхронизировать состояние React с `localStorage`.

### Реализованные возможности

- сохранение списка задач после обновления страницы;
- собственный хук `useLocalStorage`;
- автоматическая сериализация данных через `JSON.stringify`;
- чтение данных через `JSON.parse`;
- обработка ошибок с помощью `try...catch`;
- использование ленивой инициализации `useState`;
- автоматическое сохранение состояния через `useEffect`;
- счетчик с сохранением значения;
- переключение светлой и темной темы;
- сохранение черновика заметки;
- очистка списка задач;
- полная очистка сохраненных данных.


### Основные файлы проекта

| Файл | Назначение |
|------|------------|
| `src/App.jsx` | Главный компонент приложения |
| `src/hooks/useLocalStorage.js` | Кастомный хук для работы с localStorage |
| `src/components/TodoForm.jsx` | Добавление новой задачи |
| `src/components/TodoItem.jsx` | Отображение, выполнение и удаление задачи |
| `src/components/Notes.jsx` | Черновик заметок с автоматическим сохранением |
| `src/index.css` | Стили приложения |

### Выполненные упражнения

- Todo с сохранением данных.
- Счетчик с сохранением.
- Переключение темы.
- Черновик заметки.
- Кнопка «Сбросить всё».

# Часть 8. React Router

## Цель работы

Изучить принципы маршрутизации в React и научиться создавать многостраничные SPA-приложения.

### Реализованные возможности

- настройка BrowserRouter;
- маршруты через Routes и Route;
- навигация с использованием Link;
- активные ссылки через NavLink;
- динамические маршруты;
- использование useParams;
- программная навигация через useNavigate;
- общий Layout;
- использование Outlet;
- обработка страницы 404.

### Основные файлы проекта

| Файл | Назначение |
|------|------------|
| `src/App.jsx` | Настройка маршрутов приложения |
| `src/main.jsx` | Подключение BrowserRouter |
| `src/pages/Home.jsx` | Главная страница |
| `src/pages/About.jsx` | Страница с информацией |
| `src/pages/UsersList.jsx` | Список пользователей |
| `src/pages/UserProfile.jsx` | Динамическая страница пользователя |
| `src/pages/NotFound.jsx` | Страница ошибки 404 |

### Выполненные упражнения

- Главная страница.
- Страница «О проекте».
- Список пользователей.
- Динамический маршрут `/users/:userId`.
- Переход между страницами без перезагрузки.
- Кнопка «Назад».
- Страница 404.

# Запуск проектов

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```
http://localhost:5173
```

# Вывод

В ходе выполнения практической работы были успешно реализованы два самостоятельных React-проекта. Первый проект посвящен работе с `localStorage` и сохранению данных между перезагрузками страницы. Во втором проекте была изучена маршрутизация с помощью библиотеки React Router, реализована навигация между страницами, динамические маршруты и обработка несуществующих адресов.

Практическая работа позволила закрепить навыки разработки React-приложений, использования хуков, организации структуры проекта и создания современных одностраничных веб-приложений.
