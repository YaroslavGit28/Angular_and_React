# Task Tracker

В рамках данной работы было разработано React-приложение «Task Tracker» для управления списком задач.

В приложении реализована работа с задачами, получаемыми с сервиса JSONPlaceholder. Пользователь может просматривать список задач, открывать подробную информацию о каждой задаче и добавлять задачи в избранное.

В проекте реализованы следующие возможности:

- просмотр списка задач;
- просмотр подробной информации о задаче;
- создание новой задачи;
- добавление и удаление задач из избранного;
- отображение количества избранных задач;
- очистка списка избранного одной кнопкой;
- фильтрация задач по избранным через query-параметры (`?filter=favorites`);
- сохранение избранных задач в `localStorage`;
- отображение сообщений при отсутствии задач или отсутствии избранных элементов;
- отдельная страница со списком пользователей;
- просмотр подробной информации о выбранном пользователе;
- кэширование данных при помощи TanStack Query без повторной загрузки при возврате на страницу;
- обработка состояний загрузки и ошибок;
- маршрутизация между страницами приложения;
- проверка корректности ввода формы с использованием React Hook Form и Zod;
- полная типизация приложения с использованием TypeScript.

В ходе выполнения проекта были реализованы:

- работа с React Router;
- использование Context API;
- работа с React Hooks;
- использование кастомного хука для хранения данных в `localStorage`;
- получение данных с удалённого API;
- использование TanStack Query для загрузки и кэширования данных;
- использование React Hook Form совместно с библиотекой Zod;
- разделение приложения на отдельные страницы, компоненты и модули.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить приложение:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```
