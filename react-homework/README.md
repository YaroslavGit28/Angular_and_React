# Отчет по выполнению практической работы

## Цель работы

Изучить основы разработки приложений на React, научиться создавать компоненты, передавать данные через props и организовывать структуру небольшого приложения.

## Ход выполнения работы

В начале работы был создан новый проект с использованием Vite. После установки зависимостей проект был успешно запущен, благодаря чему удалось познакомиться со структурой React-приложения и назначением основных файлов.

Далее было изучено использование JSX. На практике были рассмотрены основные правила его написания: наличие одного корневого элемента, использование `className` вместо `class`, запись выражений в фигурных скобках и применение встроенных стилей через объект. Также было выполнено несколько примеров с выводом переменных, вычислений и условного отображения информации.

Следующим этапом стало изучение компонентов. Был создан отдельный компонент `Header`, который затем подключался в основном компоненте `App`. После этого была рассмотрена передача данных между компонентами с помощью props.

В основной части работы было разработано приложение «Каталог студентов». Для хранения информации использовался отдельный файл с массивом объектов. Каждый студент содержит информацию об имени, возрасте, курсе, городе, среднем балле и навыках.

Для удобства отображения приложение было разделено на несколько компонентов:

- `Header` — отображает шапку приложения;
- `StatCard` — выводит статистическую информацию;
- `StudentList` — формирует список студентов;
- `StudentCard` — отображает информацию об одном студенте.

В процессе выполнения практической работы также были выполнены дополнительные задания.

Был создан компонент `Footer`, который отображает информацию об авторских правах в нижней части страницы.

Для уменьшения повторения кода был реализован универсальный компонент `Badge`, позволяющий выводить цветные бейджи с различными подписями. После этого в карточке студента вместо встроенных стилей использовался данный компонент.

Для студентов со средним баллом не ниже 4.5 была реализована дополнительная отметка «🏆 Отличник», которая отображается автоматически при выполнении условия.

Компонент `StatCard` был доработан и получил дополнительный параметр `icon`, благодаря которому каждая карточка статистики отображает собственную иконку.

Также в карточке каждого студента был добавлен аватар, который формируется автоматически с помощью сервиса UI Avatars на основе имени студента.

Для улучшения структуры проекта отображение списка навыков было вынесено в отдельный компонент `SkillsList`, что сделало код более понятным и удобным для дальнейшего сопровождения.

## Полученные результаты

В результате выполнения практической работы было создано React-приложение, состоящее из нескольких независимых компонентов. Компоненты взаимодействуют между собой с помощью props, а данные отображаются на странице в удобном виде. Также были закреплены навыки работы с JSX, компонентами, массивами объектов и условным рендерингом.

Во время выполнения дополнительных заданий удалось лучше понять принципы повторного использования компонентов и разделения приложения на небольшие независимые части.

## Вывод

В ходе выполнения практической работы были изучены основные возможности React, необходимые для создания современных пользовательских интерфейсов. На практике удалось научиться создавать собственные компоненты, передавать данные между ними, работать с массивами объектов и организовывать структуру проекта. Выполнение дополнительных заданий позволило закрепить полученные знания и получить более полное представление о разработке приложений на React.
